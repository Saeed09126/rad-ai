# RAD AI

نسخهٔ اولیهٔ قابل اجرا از دستیار شخصی **RAD AI**، ساخته‌شده فقط با HTML، CSS و JavaScript.

## امکانات

- رابط کاملاً فارسی و راست‌چین
- محیط گفت‌وگو با تاریخچهٔ چند مکالمه
- حافظهٔ شخصی با ذخیره‌سازی مرورگری
- مدیریت وظایف و وضعیت انجام آن‌ها
- بارگذاری، نگهداری و حذف اسناد متنی
- طراحی واکنش‌گرا برای موبایل و آیفون
- اتصال‌پذیری ماژولار برای مدل هوش مصنوعی آینده
- بدون API، کلید دسترسی، بک‌اند یا سرویس پولی

## اجرا

فایل‌ها را از مخزن دریافت کنید، سپس پوشهٔ پروژه را در مرورگر باز کنید یا یک سرور محلی ساده اجرا کنید:

```bash
python3 -m http.server 8000
```

سپس آدرس `http://localhost:8000` را در مرورگر باز کنید.

در GitHub Pages نیز می‌توانید تنظیمات Pages را روی شاخهٔ `main` و پوشهٔ اصلی قرار دهید.

## محل ذخیره‌سازی

مکالمه‌ها، حافظه، وظایف و فایل‌های متنی با `localStorage` در مرورگر ذخیره می‌شوند. داده‌ها به‌صورت خودکار بین دستگاه‌ها همگام نمی‌شوند و پاک‌کردن داده‌های مرورگر آن‌ها را حذف می‌کند.
